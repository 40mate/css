후반 ‘강화’ 반복 스텝 대거 제거 → 이탈 감소 여지 큼. · 84 최다 이탈 구간 = 후반부(61–84, 전체 이탈의 절반 이상). · 이 구간 허수아비·직원·진열대 강화 반복 스텝 26개 삭제, 이탈 1위 step 81(허수아비 7 강화, 17.0%) 포함. · 온보딩 길이 84→74 단축 → 후반 반복 피로 이탈 완화 기대.
주의
신규 16개 스텝이 초·중반 집중 → 새 이탈 지점 가능성. · 핵심 = 업그레이드 튜토리얼 묶음(74#42–49) · 직원·시설 업그레이드를 ‘팝업 열기 → 해보기 → 닫기 → 이동’으로 세분화. · 스텝 세분화 = 중간 이탈 위험 증가. · 84 초반 유일 스파이크 업그레이드 진입(step 31, 3.65%)이 74에서 이 묶음으로 확장 → 실제 이탈 집중 관찰 필요.
서브스텝
신규 서브스텝 3종 = 이탈보다 이해 보조 성격. · 캐셔 고용(HireCashier) = 계산대 직원 고용/직접 계산 안내. · 은·금광산 비콘 포커스 = 계정 레벨 3·5 도달 시 새 광산 비콘으로 카메라 포커싱(다음 목표 안내). · 모두 이벤트 발동 2스텝 보조 안내 → 메인 퍼널 길이 영향 없음, 길잃음 방지(이탈 완화) 방향.
확인
배포 후 데이터 확인 항목 4가지. ① 신규 업그레이드 튜토리얼(74#42–49) 실제 이탈률 — 84 강화 반복 이탈 대체·개선 여부. ② 후반 확장 루프(74#58–73) 반복 피로 재발 여부 — 강화는 줄었으나 고용·설치 반복 잔존. ③ 종료 홀더(84#84 ↔ 74#74) 이탈 정의 — ‘완료 후 이탈’ vs 스텝 마찰 계측 기준. ④ CSV 진행순서 ↔ main_step 번호 불일치(12/13, 21·22·23) 계측 정합성.
